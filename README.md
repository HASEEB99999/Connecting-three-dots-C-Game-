# Connecting three dots (C++Game)

A classic Connect 3 (or "Three-in-a-Row") puzzle game built in **C++**.  
Match 3 or more identical pieces vertically, horizontally, or diagonally to clear them and score points.

---

## 🎮 Features

- Grid-based gameplay (3 x 3 board)
- Swap adjacent tiles to form lines of 3+
- Automatic cascade and refill after matches
- Score tracking and move counter
  
---

## 🛠️ Tech Stack

- **Language:** C++17/20

---

## 📦 How to Build & Run

### Prerequisites
- C++ compiler (GCC, Clang, or MSVC)
- Prefered DevC++ or VS Code

### Run the game
- Click compile and run on compiler
